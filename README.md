# Lateral Drift Series — сайт чемпионата

- **Сайт** — `index.html` и `config.js`, публикуются через GitHub Pages.
- **Сервер** — папка `worker/`: Cloudflare Worker и база D1. На нём работают вход через Steam и общие данные для всех посетителей: пилоты, команды, регистрации, баллы, админка, оверлеи OBS.

Пока в `config.js` пусто, сайт работает в демо-режиме на примерных данных.

## Запуск сервера (один раз)

Нужны бесплатный аккаунт Cloudflare и Node.js. Все команды выполняются в папке `worker`.

1. Войдите в Cloudflare. Откроется браузер:
   `npx wrangler login`
2. Создайте базу данных:
   `npx wrangler d1 create lds`
   Скопируйте выданный `database_id` в `wrangler.toml`.
3. Создайте таблицы:
   `npx wrangler d1 execute lds --remote --file=schema.sql`
4. Заполните в `wrangler.toml`:
   - `SITE_ORIGIN` — адрес сайта на GitHub Pages, например `https://your-name.github.io` (без пути к репозиторию);
   - `OWNER_STEAM_IDS` — ваш SteamID64 (17 цифр). Этот аккаунт всегда администратор.
5. Задайте секрет для подписи входа — любая случайная строка длиннее 32 символов:
   `npx wrangler secret put SESSION_SECRET`
6. Необязательно: ключ Steam Web API, чтобы подтягивались ник и аватар из Steam. Ключ выдаётся на <https://steamcommunity.com/dev/apikey>.
   `npx wrangler secret put STEAM_API_KEY`
7. Опубликуйте сервер:
   `npx wrangler deploy`
   Команда выдаст адрес вида `https://lds-api.<ваш-аккаунт>.workers.dev`.
8. Впишите этот адрес в `config.js`:
   `window.LDS_API = "https://lds-api.<ваш-аккаунт>.workers.dev";`
   Затем закоммитьте и отправьте изменения на GitHub.

## Публикация сайта (GitHub Pages)

1. Откройте репозиторий на GitHub → Settings → Pages.
2. Выберите «Deploy from a branch» → ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://your-name.github.io/<репозиторий>/`.

## Как устроен вход

1. Кнопка «Войти через Steam» ведёт на официальную страницу входа Steam (OpenID).
2. Сервер проверяет ответ у самого Steam и выдаёт подписанный токен на 30 дней.
3. Пароль Steam сайт не видит.

## Права

- **Обычный пилот** меняет только свой профиль: номер, машину, «О себе», регистрации, свою команду и её приглашения. Он также может подать протест.
- **Администраторы** меняют данные лиги и баллы. Это владелец из `OWNER_STEAM_IDS` и те, кому права выданы в админке.

## Проверка сервера

1. Запустите сервер локально:
   `npx wrangler dev --local`
2. В файле `.dev.vars` укажите `SESSION_SECRET="local-test-secret-0123456789abcdef0123456789"`.
3. Загрузите тестовых пользователей:
   `npx wrangler d1 execute lds --local --file=schema.sql && npx wrangler d1 execute lds --local --file=test-users.sql`
4. Запустите проверки:
   `node test.js`

## Ограничения

- Бесплатный тариф Cloudflare даёт 100 000 запросов в сутки. Открытая страница опрашивает сервер раз в 5 секунд, а пульт трансляции и оверлеи — раз в 1,5 секунды. Для лиги этого хватает с запасом.
- Если два администратора одновременно правят данные лиги, сохранится последняя правка.
- Номер пилота, заданный администратором в таблице «Пилоты и санкции», на сервере не сохраняется: номер пилот выбирает сам в профиле.
